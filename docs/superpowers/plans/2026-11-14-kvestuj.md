# Kvestuj Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A private quest-and-feed app for one friend group (max 10). Twice a week each member gets a random quest, has 12 awake hours to do it, and posts a photo or video to a shared feed.

**Architecture:**
- A static Preact webapp on GitHub Pages talks to one Google Apps Script web app.
- A Google Sheet is the database. Media lives in a Drive folder, uploaded straight from the phone through Drive resumable-upload sessions that the script creates. Media is played back through the Drive API with a referrer-restricted API key.
- All rules (time, drops, feed, recap) live in pure TypeScript in `shared/`, tested with Vitest. The same code is bundled into the Apps Script project and the webapp.

**Tech Stack:** TypeScript, Vite, Preact, Vitest, esbuild (to bundle the server into a single Apps Script file), clasp, Google Apps Script (V8), Google Sheets, Google Drive API v3, ntfy.sh, exifr (photo dates), mediabunny (video metadata and transcoding).

**Spec:** `2026-11-14-kvestuj-design.md`. **Design:** the "Kvestuj" Design canvas, 8 screens (export or screenshots in `design/`). **Quests:** `kvestuj-quests.csv`.

## Global Constraints
- **Group:** max 10 members, one group. Unique display names, case-insensitive. No passwords.
- **Drops:** 2 per member per calendar week (Mon–Sun, member's local time). Drop times are random within 10:00–22:00 local, at least 24 h apart.
- **Deadline:** 12 h of awake time. The clock pauses 22:00–10:00 local.
- **Reroll:** 1 free per member per week. New quest, same deadline.
- **Missed quest:** no penalty. The feed line reads "{name} didn't get to their quest".
- **Late posts:** allowed. Label "late". They count as done. *(plan decision)* Allowed until the member's next drop.
- **Quest choice:** never repeat a quest for a member until they've seen the whole bank. Difficulty is drawn by weight: easy 45%, medium 40%, hard 15%.
- **Posts:** one photo, or one video of up to 60 s, plus an optional caption (max 500 chars, *plan decision*). Camera or gallery. **No selfie inset.**
- **Recorded earlier:** when the capture date is before the drop, show the label "recorded earlier". Never block the post.
- **Feed lock:** posts newer than the viewer's open quest's drop are blurred until the viewer posts or their deadline passes.
- **Reactions:** exactly 😂 🔥 😮 ❤️ 👏 💀, one per member per emoji (toggle).
- **Auto-delete:** videos older than 6 months (182 days) are deleted daily. The post keeps its still frame, caption, reactions and comments, and shows "video expired". Photos are kept.
- **Monthly recap:** on the 1st, for the previous month in the group time zone: each member's done count (alphabetical, **no ranking**), the most-reacted post, and a gallery.
- **Alerts (ntfy):** each member has a private channel (new quest; 2 h of awake time left) and there is one group channel (new post). Messages never include quest text.
- **Recovery code:** format `KVS-XXXX-XXXX`, from the alphabet `23456789ABCDEFGHJKMNPQRSTUVWXYZ`. Shown once at join. Rejoining with it restores the same member and uses no new slot.
- **Media links:** Drive files are shared "anyone with the link". Media is never proxied through Apps Script.
- **House rule copy:** "House rule: always ask strangers before you film them."
- **Visual:** match the design canvas: black `#000000`, surfaces `#1C1C1E`/`#2C2C2E`, white text, secondary `#A1A1A6`, accent `#FFD60A`, Inter 400–800, pill buttons 56 px, 44 px minimum targets.
- **Cost:** €0 to run. No other services.

## Review Focus
1. **DST weeks** (last Sunday of March and of October). Drop windows and deadlines must stay 10:00–22:00 local wall-clock time, and a deadline must still be exactly 12 awake hours → tests in Task 2 and Task 3.
2. **Trigger overlap or double runs.** Two ticks at the same `now` must never drop twice, notify twice or mark missed twice → test in Task 8.
3. **Interrupted upload or reload mid-post.** No post exists until finalize. Finalize is idempotent per assignment, and a second finalize returns the first post → test in Task 7.
4. **Time-zone change mid-week.** Drops already planned keep their UTC times. The new zone applies from the next week and to the deadline of any later drop → test in Task 3.
5. **Join edge cases:** wrong group secret, an 11th member, a duplicate name with different case, and recovery with a wrong code. Each is refused with a clear message → test in Task 7.

### Task 8: Scheduled jobs

**Files:** Create `server/jobs.ts`, `server/jobs.test.ts`

**Interfaces:**
- Consumes: Tasks 2–7.
- Produces:
  - `tick(store, ports): {dropped:number, reminded:number, missed:number, planned:number}`. Runs every 15 min, inside `ports.lock`:
    1. Each member without a plan for their current local week → `planWeek` → create `scheduled` assignments.
    2. Each `scheduled` assignment with `dropAt ≤ now` → `pickQuest` (seen = that member's past questIds), `deadlineAt = awakeDeadline(dropAt, member.tz)`, status `open`, ntfy to the member channel: "New quest" / "You have 12 hours. Open Kvestuj."
